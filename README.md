# SouthFlow Hosting (ApexHost Cloud ZA)

A modern, high-performance website hosting platform demo built with **Vite, React, TypeScript, and Tailwind CSS**.

## Overview
- **Standard Annual Tier:** **R1,345 / year per website** (Fixed annual rate for South African businesses).
- **15 Demo Websites Hosted** across Teraco JB1 (Johannesburg) and Teraco CT1 (Cape Town) datacenters.
- **Key Monitored Sites:**
  - **Glenanda Hotel & Suites** (`glenanda-hotel.co.za`): Expired 27 September with an active 4-day grace period countdown before deactivation.
  - **Elijah Church International** (`elijahchurch.org.za`): Renewal due on 1 October (in 3 days).

## Features
- **Interactive SA Payment Gateways:** Renew hosting for R1,345/year using Ozow Instant EFT, Capitec Pay, Credit/Debit Card, or SnapScan.
- **Live Website Simulator:** Embedded browser viewport modal to preview what each hosted website looks like across Desktop, Tablet, and Mobile.
- **Server Management Drawer:** Quick cPanel & WordPress SSO logins, DNS zone record editor (A, CNAME, MX, TXT), PHP engine selector (8.1 - 8.3 FPM), and 1-click snapshot restore.
- **Billing & VAT Invoices:** South African SARS-compliant tax invoices with printable modal.
- **Server Health Dashboard:** Real-time uptime monitoring (99.98%) and NAPAfrica latency benchmarks (JHB: 3.8ms, PTA: 5.1ms, CPT: 14.6ms, DBN: 11.2ms).

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Start development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```
